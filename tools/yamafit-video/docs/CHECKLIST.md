# シーンごとの確認表

書き出した動画が仕様どおりかを確かめるための表です。
「自動」は `npm test` と `npm run test:e2e` で毎回確かめている項目、「目視」は静止画や動画を見て確かめる項目です。

確認用の静止画は、次のコマンドで作れます（セーフエリアの枠つき）。

```sh
npm run export -- <プロジェクトのフォルダ> --frames 0-900 --stills 2.5,7,10.5,14.5,18.7,25,29.9 --guides
```

## 全体

| # | 確認すること | 方法 |
|---|---|---|
| A1 | 1080×1920、30fps、900フレーム、H.264、yuv420p、尺30.0秒±0.1秒、faststart | 自動（書き出しのたびに ffprobe で検証） |
| A2 | 同じ入力から同じフレームが出る。描く順番を変えても変わらない | 自動（`npm run verify`） |
| A3 | 文字・写真・ロゴが、セーフエリア（上240・下400・左60・右140px を除いた範囲）の中にある | 自動（30秒ぶんを0.5秒おきに確認） |
| A4 | 文字・写真・ロゴが、互いに重ならない | 自動（同上） |
| A5 | 文字が枠からはみ出さない（入力の上限いっぱいの文字数でも） | 自動（商品名40文字、特徴28文字、役割24文字、まとめ42文字で確認） |
| A6 | 画面に出る文は、入力した文だけ（システムが足すのは「特徴 1/2」「パーツ 1/4」「まとめ」の見出しのみ） | 自動 |
| A7 | 登録・確認していないパーツが映らない | 自動 |
| A8 | 動きがシーンの境目で飛ばない | 自動 |
| A9 | 透かし「検証用・公開不可」が全フレームに入っている（透かしONのとき） | 目視 |
| A10 | 行の先頭に「、」「。」や小さい文字が来ない | 自動（折り返しの規則）＋目視 |

### 1. 全体像（0〜5秒）

| # | 時刻 | 確認すること | 方法 |

| S1-2 | 0〜5秒 | 商品がゆっくり回転している（初期値は毎秒36度） | 自動 |

| # | 時刻 | 確認すること | 方法 |
