# 同梱フォント

動画の中の文字は、ここにあるフォントだけで描きます（どの環境でも同じ結果にするため）。
サイト（css/style.css）と同じ書体です。

| ファイル | 書体 | ライセンス |
|---|---|---|
| `ZenKakuGothicNew-Bold.ttf` | Zen Kaku Gothic New 700 | SIL Open Font License 1.1（`OFL-ZenKakuGothicNew.txt`） |
| `ZenKakuGothicNew-Black.ttf` | Zen Kaku Gothic New 900 | 同上 |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono 500 | SIL Open Font License 1.1（`OFL-IBMPlexMono.txt`） |

入手元：npm の `@expo-google-fonts/zen-kaku-gothic-new`、`@expo-google-fonts/ibm-plex-mono`（Google Fonts と同じファイル）。
