## 形（近似モデル）の根拠

`project.json` の `model.shape` に入っている数値（単位cm）の決め方です。

| 部分 | 決め方 | 確かさ |
|---|---|---|
| 本体の高さ・幅・奥行きの最大値 | 公式の寸法 47×24×18cm | 公式の値 |
| 下半分の幅と、底の丸み | 背面の写真の輪郭を測った。写真から求めた本体の幅は約23.4cmで、公式の24cmと合っている | 写真から測定 |
| 上部の幅と丸み | 背面の写真ではショルダーストラップに隠れて見えないため、正面（斜め）の写真から読み取った | 読み取り（誤差あり） |
| 奥行きの変化（横から見た形） | **横からの写真がないため推定。** 最大18cm（公式）で、下寄りがふくらみ、上に向かって薄くなる形とした | 推定 |
| ショルダーストラップの位置と太さ | 背面の写真から読み取った。背面からどれだけ浮くかは推定 | 読み取り＋推定 |
| チェストストラップの高さ | 背面の写真から測った（底から約31cm） | 写真から測定 |
| ベルト | 背面の写真で、細いベルトであることを確認。写真では垂れ下がっているが、3Dでは背負う側に輪の形で置いた | 形は様式化 |
| サイドポケットの範囲 | 正面（斜め）の写真から読み取った。片側しか写っていないが、公式に「両サイド」とあるため左右対称にした | 読み取り |
| 持ち手 | 正面・背面の両方の写真に写っている | 写真で確認 |

再現していないもの：ロゴ（SALOMON、TRAILBLAZER 10）、正面の切り替え線とジッパー、バンジーコード、反射材、生地の織り目、背面パッドの模様、バックルの細かい形。

横から撮った写真と、正面を真っ直ぐ撮った写真があれば、奥行きと正面の細部をさらに合わせられます。

## 色

公式の商品写真（正面・背面）から取り出した、黒に近い濃いグレーです（本体 `#333234`、ポケット `#2B292B`、ストラップと背面 `#29282A`）。
公式のカラー名は「BLACK / ALLOY」。

## 写真
